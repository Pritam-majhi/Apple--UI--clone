# Apple UI Clone

A responsive Apple Store-inspired website built using HTML, CSS, and small  JavaScript.

## Time Taken

**21 Hours**

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Features

- Responsive Apple-style navigation bar
- Product category section
- Promotional offer cards
- Latest products section
- Apple Store benefits section
- Education section
- Responsive design for desktop, tablet, and mobile
- Hover effects and card interactions
- Typing animation using JavaScript
- Font Awesome icons
- Google Fonts
- Apple-inspired product images and backgrounds
