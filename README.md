# Apple UI Clone

A responsive Apple Store-UI clone built using HTML, CSS, and small  JavaScript.

## Time Taken

**21 Hours**

## [Live Demo] (https://pritam-majhi.github.io/Apple--UI--clone/)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## What I Learned

I learned how to build responsive layouts, use CSS flexbox and media queries, add hover effects, work with external resources, and create basic JavaScript animations.

## Features

- Responsive Apple-style navigation bar
- Product category section
- Promotional offer cards
- Latest products section
- Apple Store benefits section
- Education section
- Responsive design for desktop, tablet, and mobile
- Hover effects and card interactions
- Typing animation using JavaScript
- Font Awesome icons
- Google Fonts
- Apple-inspired product images and backgrounds
